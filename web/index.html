CDB OpenTakeoff

Ductape-Build's downstream fork of OpenTakeoff by Kentucky AI, licensed AGPL-3.0-only. This is not the official upstream site or npm MCP release. The takeoff canvas needs JavaScript.

Build this fork's MCP locally and run node mcp/dist/server.js from the repository root. Normal measurement tools run an independent offline session; only the explicitly named live-browser tools target an opt-in connected canvas.
